# FitTrack Pro — Marketplace Listing

## Product title
FitTrack Pro — Offline Pomodoro Timer & Task Manager

## Short description
A responsive, offline-first productivity web app combining a customizable Pomodoro timer, task manager, progress dashboard and local data backups. Built with HTML5, CSS3 and Vanilla JavaScript.

## Full description
Plan tasks, set priorities, focus in timed intervals and review your progress in one workspace. FitTrack Pro includes a dashboard for active tasks, completion rate, focus time and consistency streaks. Its Pomodoro timer supports focus, short-break and long-break modes with editable durations.

The app stores records in the browser and supports JSON backup, JSON restore and CSV export. A centralized configuration object makes white-label customization simple.

## Features
- HTML5, CSS3 and Vanilla JavaScript
- No external runtime dependencies
- Offline operation with browser local storage
- Responsive desktop, tablet and mobile layout
- Dashboard and productivity charts
- Pomodoro timer with three modes
- Editable timer durations
- Task creation, editing, completion and deletion
- Categories, priorities, due dates, notes and colours
- Search, filters and sorting
- Light and dark themes
- JSON backup and restore
- CSV task export
